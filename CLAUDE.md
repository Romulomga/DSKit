# DSKit

Design system em SwiftUI, a base visual dos apps iOS do dono. Ver o `README.md` e o `DESIGN.md`.

**Gêmeo por conceito:** `~/DSKit-Android` (`github.com/Romulomga/DSKit-Android`). Mesmo nome e mesma regra quando o
problema existe nas duas plataformas; o que é de uma só é dito. A base não visual é o CoreKit (`~/CoreKit`): o que não
desenha vai para lá, nunca para cá.

Os apps usam o DSKit por `minorVersion` (até o próximo minor), nunca por versão exata: mudança é release com tag aqui,
nunca uma cópia local no app.
